# 实施计划

目标：本地合并十份销售订单表，输出可追溯结果。

架构：纯函数标准化与审计核心；ExcelJS 读取 `.xlsx` 为保留行坐标的矩阵；导出层写工作簿、JSON 和静态报告。公开运行仅依赖 Node.js 22+ 和 ExcelJS。

1. 先写测试，确认基础字段解析、金额整数分、行去向、明细唯一键和合计的失败。实现核心与十份可重复生成的样例。提交初版。
2. 写对抗用例：同键冲突、多行订单、数值零/空、退货、歧义日期、坏金额、公式、重复表头、合计、未知表结构。确认初版暴露的问题，再修到通过。提交第一次迭代。
3. 先写修正绑定、重复重跑、不可覆盖输入、未知配置失败等测试。实现修正审计与最终报告。提交第二次迭代。
4. 两阶段只读审查：先核对设计规格，再检查代码错误和数据丢失风险。修正后复跑相关测试。生成与核查最终 `.xlsx`，观察所有输出工作表，记录验证结果。
5. 双语 README 记明真实结果、使用方法、业务规则、局限和模拟数据性质。创建公开仓库并推送，核验远端文件与提交。
